PM AGENT IN MICROSOFT 365 COPILOT · SETUP SHEET
SPARK · AI powered PM practice
Companion to the video "Build your PM Agent in Copilot". Copy and paste each block into Agent Builder.
Menu names and available knowledge sources can vary with your Copilot version and tenant settings.


BEFORE YOU START
1. Copilot Premium license with Agent Builder activated.
2. Access to the project's SharePoint site and Teams channels. The agent sees only what you can see.
3. Transcription switched on for project meetings.
4. Data rules agreed: project content only, no personal or HR information.


STEP 1 · OPEN AGENT BUILDER
Microsoft 365 Copilot > Agents > Create agent.


STEP 2 · NAME AND DESCRIPTION  (Configure tab)
Name:
Project Pulse

Description:
Weekly status drafts and early risk alerts for my project, from mail, meetings, chats and SharePoint.


STEP 3 · INSTRUCTIONS  (replace [project] with your project name)
You are Project Pulse, an agent working for the project manager of [project].

EVERY WEEK, DRAFT A STATUS UPDATE WITH
- Proposed overall rating (the PM sets the final rating)
- Milestones: baseline vs forecast, from the plan
- Top 5 risks and issues, with owners
- Decisions and actions from this week's meetings
- Open asks for management

RULES
- Name the source of every line: mail, meeting, chat or file.
- List conflicts and missing inputs under NEEDS PM CHECK.
- Never set the rating or make a decision.
- Leave out personal and HR information.

ALERT ME AT ONCE WHEN YOU SEE
- A date that slips, or a dependency that is overdue
- "Should be fine" about a critical item
- The same issue raised twice without an owner


STEP 4 · KNOWLEDGE
- SharePoint: the project site, plus the project plan and the RAID log
- Email: on
- Teams chats: on
- Teams meetings: on
- Search the web: off


STEP 5 · STARTER PROMPTS
Weekly status
  Draft this week's status update for [project], with a source for every line.
New risks
  Show new risks and slipped dates since Monday, with the evidence for each.
Decisions and actions
  List this week's decisions and actions from meetings, with owners and dates.


STEP 6 · TEST IN THE PREVIEW
Run "Weekly status" and check:
- Is every line sourced?
- Are conflicts flagged under NEEDS PM CHECK?
- Is anything confidential or personal left out?
When a test fails, add one rule to the instructions and run it again.


STEP 7 · MAKE IT PROACTIVE
- Schedule "Weekly status" for every Friday, 08:00.
- Schedule "New risks" for every weekday, 08:30.
- Turn on notifications.
- For instant alerts when a new risk appears (for example a new supplier email or a new RAID entry),
  ask your Copilot Studio team to add an event trigger to the same agent.


STEP 8 · CREATE AND SHARE
Select Create. Share with your project team (specific people), or keep it for yourself.
Everyone sees only the content they already have access to.


FIVE GUARDRAILS
1. The agent respects your permissions.
2. Every line names its source.
3. The project manager owns every rating and decision.
4. No personal data in the output.
5. A person checks before anything is sent.
