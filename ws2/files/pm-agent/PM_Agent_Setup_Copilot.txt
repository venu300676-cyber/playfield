WHAT IS AN AGENT, AND WHY NOT JUST A PROMPT?
A normal prompt is a one-time question: you type, Copilot answers, and next time you start from zero.
An agent is Copilot set up once for a specific job, with its own instructions, the knowledge it may
use and ready-made prompts. It keeps its role and follows your rules every time you use it.

                 NORMAL PROMPT                      AGENT
Context          Re-typed every week                Built in, once
Output           Changes with your wording          Same structure every week
Trust            Not checked against your rules     Every finding with its source
Team             Stays in your own chat             Shared with the project team

Set it up once, and it pays you back every week.

BEFORE YOU START
1. Copilot Premium license with Agent Builder activated.
   Not enabled yet? Request it here: https://forms.cloud.microsoft/e/KjfvXMztWp
2. Access to the project's SharePoint site and Teams channels. The agent sees only what you can see.
3. Transcription and Facilitator switched on in Teams project meetings.
4. Data rules agreed: project content only, no personal or HR information.


STEP 1 · OPEN AGENT BUILDER
In the Copilot app, select New agent in the left pane (under Agents).
Or open the Agent Store (More agents) and select Create agent.


STEP 2 · NAME AND DESCRIPTION
Agent Builder opens on "Build your own specialist agent". You can start from a template
(for example Project Delta Digest) or describe the agent in the chat. For full control,
select Skip to go to the Configure page.
Select the pencil next to "New Agent" to name it, and fill in "Describe your agent".
Name:
Project Pulse

Description:
Weekly status drafts and early risk alerts for my project, from mail, meetings, chats and SharePoint.


STEP 3 · INSTRUCTIONS  (Configure > Instructions; replace [project] with your project name)
Tip: "Suggest improvements" can sharpen the wording. Read every change before you keep it.

You are Project Pulse, an agent working for the project manager of [project].

EVERY WEEK, DRAFT A STATUS UPDATE WITH
- Proposed overall rating (the PM sets the final rating)
- Milestones: baseline vs forecast, from the plan
- Top 5 risks and issues, with owners
- Decisions and actions from this week's meetings
- Open asks for management

RULES
- Name the source of every line: mail, meeting, chat or file.
- List conflicts and missing inputs under NEEDS PM CHECK.
- Never set the rating or make a decision.
- Leave out personal and HR information.

ALERT ME AT ONCE WHEN YOU SEE
- A date that slips, or a dependency that is overdue
- "Should be fine" about a critical item
- The same issue raised twice without an owner


STEP 4 · KNOWLEDGE  (Configure > Knowledge)
By default the agent can already search everything Copilot can: cloud files (OneDrive and
SharePoint), your Outlook mailbox, Teams meetings and messages, and the web.
- Add knowledge: the project's SharePoint site, plus the project plan and the risk log
- Work content > Cloud files: on
- Work content > Outlook: on
- Work content > Teams: on (meetings and messages)
- Copilot connectors: leave off unless your project data lives in a connected system
- Web search: off, so answers come only from your work content


STEP 5 · SUGGESTED PROMPTS  (Configure > Suggested prompts: a Title and a Message for each)
Weekly status
  Draft this week's status update for [project], with a source for every line.
New risks
  Show new risks and slipped dates since Monday, with the evidence for each.
Decisions and actions
  List this week's decisions and actions from meetings, with owners and dates.


STEP 6 · TEST IT  (Preview tab)
Run the "Weekly status" suggested prompt and check:
- Is every line sourced?
- Are conflicts flagged under NEEDS PM CHECK?
- Is anything confidential or personal left out?
When a test fails, add one rule to the instructions and run it again.


STEP 7 · MAKE IT A ROUTINE
Agent Builder agents run only when you ask them; there is no scheduling.
- Book a recurring 15-minute calendar slot every Friday at 08:00: open Project Pulse and select "Weekly status".
- Book a recurring 5-minute slot every weekday at 08:30: select "New risks".
- For automatic alerts without opening the agent (for example on a new supplier email or a new risk log entry),
  ask your Copilot Studio team to rebuild the agent with a schedule or an event trigger.


STEP 8 · CREATE AND SHARE
Select Create at the top right. Share with your project team (specific people), or keep it for yourself.
Everyone sees only the content they already have access to.


FIVE GUARDRAILS
1. The agent respects your permissions.
2. Every line names its source.
3. The project manager owns every rating and decision.
4. No personal data in the output.
5. A person checks before anything is sent.
